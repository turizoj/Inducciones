# SIGEIN · Frontend

Aplicación web de SIGEIN hecha con React y Vite.

```bash
npm install
npm run dev      # desarrollo en http://localhost:5173
npm run lint     # revisión del código
npm run build    # versión para publicar en la carpeta dist/
```

Configure la dirección de la API en `.env` (vea `.env.example`).

La instalación completa y los manuales técnico y de usuario están en el [README principal](../README.md).
